# JS-PROGRAMS

A collection of JavaScript programs demonstrating various concepts from basic to advanced.

## List of Experiments

1. **Experiment 1**: Basic JavaScript programs using variables, data types, operators, and control statements
2. **Experiment 2**: Embedding and linking JavaScript with HTML pages
3. **Experiment 3**: BOM objects (Window, History, Navigator, Screen) for browser interaction
4. **Experiment 4**: DOM manipulation techniques
5. **Experiment 5**: Dynamic web pages using JavaScript events
6. **Experiment 6**: Node.js environment setup and execution
7. **Experiment 7**: Server-side applications using Node.js and Express with RESTful APIs
8. **Experiment 8**: Database operations using MongoDB with Node.js

## How to Run

### Experiments 1-5 (Browser-based)
Open the respective HTML files in a web browser.

### Experiments 6-8 (Node.js-based)
1. Install Node.js from [nodejs.org](https://nodejs.org/)
2. Navigate to the experiment folder
3. Run `npm install` (for experiments 7 and 8)
4. Run `node <filename>.js`
