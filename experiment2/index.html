Experiment 2: Embedding & Linking JavaScript with HTML

1. Internal JavaScript (in <head> section)

JavaScript code written inside <script> tags in the HTML document.

2. Inline JavaScript (in HTML elements)

JavaScript code written directly in HTML element attributes.

3. External JavaScript (linked file)

JavaScript code written in a separate .js file and linked using <script src="...">.

4. JavaScript Comments

Demonstrating single-line and multi-line comments.

5. JavaScript Keywords

Demonstrating various JavaScript keywords like var, let, const, if, else, for, function, return, etc.
